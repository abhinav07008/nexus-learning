# NEXUS
Functional local-first adaptive learning PWA.

## What works
- Responsive iPhone-first interface
- On-device persistence with localStorage
- 5-question baseline diagnostic
- Adaptive recommendation based on demonstrated mastery
- Curriculum with 8 connected foundations
- Focus timer and study-session logging
- Active recall with immediate feedback
- Topic tests with scoring and mastery updates
- Automatic next-topic recommendation
- Streak and XP tracking
- Learner evidence/profile view
- JSON export and reset
- Offline service-worker caching
- GitHub Pages deployment

## Important limitation
This version does **not** pretend to contain a remote AI model. It is the functional adaptive-learning core. A secure AI backend can be added later without exposing an API key in GitHub Pages.

## Deployment
GitHub Pages publishes the repository using the existing Actions workflow.
